# educational-kpi-analysis

## 概要
pythonを用いた学習データの分析。学習効果（成績）に影響する要因を探索したプロジェクト。


##使用データセット
Kaggleにて「Student Performance Dataset」を使用
https://www.kaggle.com/datasets/nabeelqureshitiii/student-performance-dataset


##使用技術
Python
 pandas
 matplotlib
 plotly
 statsmodels


##分析内容
・生徒の成績の要因分析


##結果
・学習時間と得点、学習時間と成績に強い相関が見られた
・他はほとんど相関が見られなかった
・回帰分析の結果、週の学習時間が1時間増えると、得点が1.8点増えることが分かった


##提案
・上記の結果、「学習時間の確保」が成果（得点、成績）に大きく寄与すると判断し、学習量増加の提案をしていく。
・まずは学習時間が確保できていない生徒については、確保できていない理由をヒアリングしていく。中には「何から手をつければいいかわからない」「問題が難しい」場合もあるため、
　「何から手をつければいいか」⇒教材のページを週単位あるいは日単位で指定し、タスクの見える化を行う
  「問題が難しい」⇒テキストの難易度を下げる。あるいはプリントを印刷し、生徒自身で取り組めるレベルに落としてあげる。
・学習時間がある程度確保できている生徒については、更なる学習時間確保に努めていく。まずは「そもそも学習できていることが素晴らしい」と褒め、自身の行動に自信を持たせる。
　加えて、小さく目標を高めてあげ、徐々にクリアしていけるようサポートする。
・自宅での学習が難しい生徒については、放課後の教室を開放したり、基本的には無料である図書館や公民館の利用を促す。場合によっては有料である学習塾の利用を保護者に提案する。

・実際問題、スタートが20点台の生徒も、「できるところまで戻る」「演習中心」のスタイルで勉強を進めた結果、平均点まで点数を上げたケースも教室長として経験した。
　やはり、学習時間を確保することは生徒の成績、ひいては成功体験にとって重要な要素となり得る。
